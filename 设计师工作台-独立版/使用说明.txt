# 设计师工作台 - 独立版

## 简介

这是一个纯前端静态应用，不依赖任何后端服务器，所有数据存储在浏览器本地（localStorage + IndexedDB）。可以永久免费使用，不会产生任何费用。

## 文件说明

```
设计师工作台-独立版/
├── index.html          # 主页面
├── assets/
│   ├── index-*.css     # 样式文件
│   └── index-*.js      # 应用代码
├── 启动工作台.bat       # Windows 本地启动脚本
└── 使用说明.txt         # 本文件
```

## 使用方式

### 方式一：Windows 本地启动（推荐电脑使用）

1. 解压压缩包
2. 双击运行 `启动工作台.bat`
3. 脚本会自动检测 Python 或 Node.js 并启动本地服务器
4. 浏览器自动打开 `http://localhost:8080`
5. 使用完毕后，在命令行窗口按 Ctrl+C 停止服务器

**前提条件**：电脑需安装 Python 或 Node.js（任一即可）
- Python 下载：https://www.python.org/downloads/
- Node.js 下载：https://nodejs.org/

### 方式二：部署到免费静态托管平台（推荐手机使用，功能完整）

将整个文件夹上传到以下任意免费平台，即可获得永久免费的在线访问地址，手机和电脑都能使用：

#### GitHub Pages（推荐，永久免费）
1. 注册 GitHub 账号：https://github.com
2. 点击右上角 "+" → "New repository" 创建新仓库
3. 仓库名随意（如 my-workbench），选择 Public
4. 上传本文件夹所有文件到仓库
5. 进入仓库 Settings → Pages
6. Source 选择 "Deploy from a branch"，Branch 选择 "main"，文件夹选 "/(root)"
7. 点击 Save，等待几分钟
8. 获得 `https://用户名.github.io/仓库名/` 的永久访问地址

#### Vercel（最简单）
1. 访问 https://vercel.com，用 GitHub 登录
2. 点击 "Add New" → "Project"
3. 上传本文件夹或连接 GitHub 仓库
4. 自动部署，获得免费域名（xxx.vercel.app）

#### Netlify（拖拽上传）
1. 访问 https://app.netlify.com/drop
2. 直接将本文件夹拖放到页面上
3. 自动部署，获得免费域名

#### Cloudflare Pages
1. 访问 https://pages.cloudflare.com
2. 连接 GitHub 或直接上传
3. 免费部署，全球 CDN 加速

### 方式三：手机本地使用

1. 将本文件夹传到手机
2. 手机上安装 "HTTP Server" 类 App（如 Simple HTTP Server）
3. 指向本文件夹，启动服务器
4. 用手机浏览器访问显示的地址
5. 在浏览器菜单中选择「添加到主屏幕」，即可像 App 一样使用

**更简单的方式**：使用方式二部署到免费平台后，用手机浏览器访问地址，再「添加到主屏幕」。

## 数据安全

- 所有数据存储在你的浏览器本地，不会上传到任何服务器
- 清除浏览器数据会导致数据丢失，请定期备份重要内容
- 创作素材的文件存储在 IndexedDB 中，容量通常可达数百 MB
- 换设备或换浏览器后数据不共享，需重新录入

## 常见问题

**Q：为什么不能直接双击 index.html 打开？**
A：浏览器安全策略禁止在 file:// 协议下加载 JavaScript 模块，需要通过 HTTP 服务器访问。使用「启动工作台.bat」或部署到静态平台即可。

**Q：部署后数据会丢失吗？**
A：不会。数据存储在浏览器本地，与部署平台无关。但换浏览器或清除数据会丢失。

**Q：这个应用会收费吗？**
A：不会。这是纯前端静态应用，没有后端服务器，没有任何收费项目。部署到 GitHub Pages 等平台也是永久免费的。

**Q：手机上怎么安装成 App？**
A：用手机 Chrome 浏览器访问部署后的地址，点击菜单 →「添加到主屏幕」，即可像 App 一样使用。
